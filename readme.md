# Countdown

Simple countdown built for use in the [DECAGONE](https://www.tuesdayknightgames.com/products/decagone) module for [Mothership](https://www.tuesdayknightgames.com/pages/mothership-rpg).

[Deployed here](https://countdown-decagone.netlify.app/).

Two modes, switchable in Settings: the default LCD elevator countdown, and
a Shadowdark TORCH mode — a grim red-on-black 60-minute burn that gutters
out to black at zero and relights on tap.

Uses [DSEG7 Classic bold font](https://www.keshikan.net/fonts-e.html) for
the elevator mode and [Courier Prime](https://github.com/quoteunquoteapps/CourierPrime)
for torch mode, both licensed under the [SIL Open Font License Version 1.1](http://scripts.sil.org/OFL).
